# TRADEPRO1

TRADEPRO1 is a mobile-friendly forex trading demo website for Kenyan users. The project presents a professional trading platform with demo and real account options, M-PESA flows, education, and support content while clearly separating demo-only functionality from real-money trading.

## Features

- Dark navy blue and gold/green trading dashboard styling
- Responsive home page and account flow for mobile, tablet, and desktop
- Demo-trading simulator with EUR/USD, GBP/USD, and USD/JPY pricing
- Real account onboarding page with required compliance disclaimers
- M-PESA deposit and withdrawal planning pages
- Forex learning section with beginner-friendly risk education
- Contact and support page with FAQ and form layout
- Static HTML/CSS/JavaScript project ready for GitHub Pages

## Run locally

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish to GitHub Pages

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to Settings → Pages.
4. Under Source, select the `main` branch and root folder (`/`) if using static files.
5. Save the settings.
6. GitHub will publish the site to:
   `https://<username>.github.io/tradepro1/`

## Important notice

This is a free demo website prototype. It does not accept real customer funds, does not provide live forex execution, and does not integrate with a regulated broker or payment provider yet. Real-money trading and M-PESA payment workflows should only be enabled after proper legal, compliance, security, and verification checks are completed in Kenya.
